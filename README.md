## ✨ Features

- 🔥 **Trending Prompts Live Feed (热门提示词更新展示区)**: Real-time showcase of viral AI video prompts across TikTok, Bilibili, Runway Gen-3, Sora & Kling AI with one-click apply & copy.
- 🎭 **Character Lock 2.0 (角色一致性锁)**: Generate character anchors with fixed facial features, proportions, and outfits across video scenes.
- 🎬 **12 Commercial Styles**: Cyberpunk, Cinematic Sci-Fi, Pixar 3D Animation, Oriental Ink Wash, Anime, Film Noir, and more.
- 📜 **3-Shot Storyboard Builder (三镜头分镜生成器)**: Instantly generate Shot 1 (Establishing), Shot 2 (Medium Action), and Shot 3 (Close-up Peak) with linked character anchors.
- ⚡ **Offline Web App Single-Page Forge**: Built-in standalone single-file HTML app (`prompt-forge.html`) for offline prompt generation.
- 💎 **PRO Prompt Vault (1,880+ Prompts)**: Integrated commercial prompt vault & Gumroad monetization workflow.

## 🚀 Quick Start (Local Development)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Charlieningxia/storycraftAI.git
   cd storycraftAI
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

## 🌐 Deploy Your Own Copy (Free Hosting)

### Deploy to Vercel
1. Go to [Vercel](https://vercel.com) and sign in with GitHub.
2. Click **Add New Project** and import `Charlieningxia/storycraftAI`.
3. Click **Deploy**! Your site will be live on a custom `.vercel.app` URL in under 1 minute.

### Deploy to Netlify
1. Log in to [Netlify](https://netlify.com).
2. Click **Import from Git** and select `Charlieningxia/storycraftAI`.
3. Build command: `npm run build`, Publish directory: `dist`.
4. Click **Deploy Site**.
